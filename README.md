# CODEX-UZB — сайт команды разработчиков

Одностраничный сайт-визитка на **React + Vite** для привлечения новых заказов.
Дизайн построен на фирменном стиле логотипа: тёмная тема и градиент cyan → blue → violet.

## Запуск

```bash
npm install
npm run dev      # http://localhost:5173
npm run build    # сборка в dist/
npm run preview  # локальный просмотр сборки
```

## Языки

Сайт на четырёх языках: русский, узбекский, английский и китайский. Язык определяется
по настройкам браузера, запоминается в `localStorage` и переключается в шапке.

Все четыре файла в `src/i18n/` имеют одинаковую структуру — правя текст, сохраняйте её
и одинаковое количество элементов в массивах (услуги, проекты, вопросы и т.д.):
карточки собираются по индексу вместе с данными из `src/data/site.js`.

Чтобы добавить пятый язык: скопируйте `ru.js`, переведите и добавьте импорт
в `src/i18n/index.jsx` (`languages` и `languageList`).

## Форма заявки

Скопируйте `.env.example` в `.env` и заполните:

- **`VITE_FORM_ENDPOINT`** — URL, куда POST-запросом уходит заявка (Formspree, Getform,
  свой backend или Telegram-бот через серверную функцию). Данные отправляются JSON-ом:
  `{ name, contact, service, budget, message, text }`.
- Если переменная **не задана** — форма копирует текст заявки в буфер обмена
  и открывает ваш Telegram, чтобы клиент вставил её в чат. Сайт работает сразу,
  без бэкенда.
- `VITE_TELEGRAM` — аккаунт для связи (`codex_uz`), `VITE_TELEGRAM_CHANNEL` — канал (`codex_uzb`),
  `VITE_INSTAGRAM`, `VITE_PHONE`, `VITE_EMAIL` — остальные контакты в шапке, форме и футере.

> Токен Telegram-бота во фронтенде хранить нельзя — он будет виден всем.
> Для отправки прямо в бота используйте serverless-функцию (Vercel / Netlify) и укажите
> её URL в `VITE_FORM_ENDPOINT`.

## Перед публикацией

1. Замените демо-кейсы в `projects` (`src/data/site.js`) на реальные, добавьте `link`.
2. Проверьте цифры в `stats` — сейчас там ориентировочные значения.
3. Проверьте контакты в `contacts` (`src/data/site.js`) — ссылки собираются в `contactLinks`.
4. Соберите (`npm run build`) и залейте `dist/` на Vercel, Netlify или свой хостинг.
